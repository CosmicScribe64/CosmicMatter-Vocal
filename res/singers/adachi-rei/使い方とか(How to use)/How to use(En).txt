[Compatibility with UTAU engines]


very good   moresampler(ver0.8.3),TIPS,f2resamp
good        resampler,vs4u,fresamp,bkh01,doppeltler
not so bad  EFB-GW
bad         tn_fnds,world4utau


TIPS            : compatible with all ''voice''
moresampler     : strong voice. 
resampler       : compatible with all ''sound''(all instrumental voice can use). a little noisy,a little strong. recommend flag B0
f2resamp        : compatible with all ''sound''
doppeltler      : recommend flag B0.
vs4u            : a little noisy,strong 


If you use ust file whitch someone made, you'd better initialize every parameters on ust.
AdachiRei,this library isn't including human voice, so, sometimes the data whitch editted for usual voice, isn't fit.
If you use another moresampler version,(ver0.6.1→ver0.8.3) you should delete old llsm file.

In most cases, it is better to use CV.
